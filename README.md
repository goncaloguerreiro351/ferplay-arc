# Ferplay – Fiche technique en ligne (prototype)

Formulaire en ligne qui remplace la fiche ARC « Industriel Fer » : le client remplit ses produits, la page vérifie les règles du configurateur et génère la fiche PDF à envoyer à Ferplay.

Page : https://goncaloguerreiro351.github.io/ferplay-arc/

Tout est dans `index.html` (page statique, aucune donnée envoyée à un serveur).
